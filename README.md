# 达人筛号系统 Demo

## 项目概述
达人筛号系统是一款面向品牌方、MCN机构的智能达人筛选与评估平台，通过多维度数据分析和AI算法，帮助客户快速找到最匹配的内容创作者。

## 技术栈

### 前端
- React 18
- Ant Design 5
- ECharts 5
- Axios

### 后端
- Node.js + Express
- JSON文件数据存储（Demo版本）

### AI评分
- 自研评分算法
- 四维度评估：适配度、影响力、粉丝粘性、爆款潜力

## 快速开始

### 1. 安装依赖

#### 后端
```bash
cd backend
npm install
```

#### 前端
```bash
cd frontend
npm install
```

### 2. 启动服务

#### 启动后端服务（端口：3001）
```bash
cd backend
npm start
```

#### 启动前端服务（端口：3000）
```bash
cd frontend
npm start
```

### 3. 访问系统
浏览器打开：http://localhost:3000
